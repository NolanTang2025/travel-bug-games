# 扫码即玩 · Ins / 小红书

## 链接

**https://mnemo-games.vercel.app/play**

## 支持

| 平台 | 方式 |
|------|------|
| **Instagram** | 公开帖 → 分享 → 复制链接 |
| **小红书** | App 分享 → 复制**完整**链接（含 xsec_token 更稳） |
| **小红书备选** | 链接读不到 → 页内「上传帖子截图」 |

## 用户操作

1. 扫 QR 或打开 `/play`
2. 复制 Ins 或小红书帖子链接
3. 粘贴 → **一键生成游戏**（约 15–25 秒）

无需登录。

## 小红书注意

- 小红书常拦截服务器自动抓取；若链接失败，**用截图上传**（同样能玩）
- 务必从 App 内「分享 → 复制链接」，不要只手打 explore 地址

## 直达链接

```
/play?url=https://www.instagram.com/p/xxxxx/
/play?url=https://www.xiaohongshu.com/discovery/item/xxxxx?...
```
